# 쿠팡 파트너스 상품 수집 — 설정 가이드

## 🚫 `npm run run` (브라우저 자동화)은 현재 차단됨

`generate-coupang-link.js`(Playwright로 쿠팡 파트너스 페이지 자동 순회)는 2026-08-10 기준
쿠팡의 Akamai WAF가 자동화 자체를 감지해서 `Access Denied`로 막습니다. 헤드리스든
헤드풀이든, 신규 로그인이든 저장된 세션이든 동일하게 막힘 — 로그인 문제가 아니라
봇 탐지입니다. 이 차단을 우회하는 시도(스텔스 플러그인, 지문 위장 등)는 하지 않습니다.

쿠팡 공식 Open API(자동화 없이 정식으로 링크 생성/상품 검색 가능)는 매출액 기준
미달로 신청 불가 상태입니다. 그래서 **당장은 `npm run add`(아래) 로 사람이 직접 확인한
정보를 입력하면 이미지 합성/업로드/시트 저장만 자동화하는 방식**을 씁니다. 매출 기준을
채워 Open API를 쓸 수 있게 되면 `generate-coupang-link.js`를 API 기반으로 다시 만들 수
있습니다.

## 두 가지 실행 방법

1. **`npm run add`** (현재 권장) — 쿠팡에서 사람이 직접 확인한 상품 정보를 프롬프트로
   입력하면, 이미지 합성 + 구글 드라이브 업로드 + 시트 append를 자동으로 처리합니다.
   "링크 생성" 버튼 클릭만 쿠팡 파트너스 UI에서 직접 하면 됩니다.
2. **`npm run run`** (현재 차단됨, 참고용으로 남겨둠) — 로그인(수동) → 추천상품 목록
   순회 → 신규 상품만 "링크 생성" → 제목/가격/제휴링크를 구글시트 큐에 append까지
   전부 자동화하는 스크립트였으나 위 이유로 현재 못 씀.

**둘 다 사용자 PC에서 직접 실행**되어야 합니다 (n8n Cloud에는 브라우저 자동화 노드가 없습니다).

## ⚠️ 기존에 쓰던 시트가 있다면 (컬럼 추가 마이그레이션)

이미지 합성 기능 추가하면서 컬럼 순서가 `... | affiliate_link | image_url | posted` 로 바뀌었습니다 (기존엔 `affiliate_link` 다음이 바로 `posted`). 이미 쓰던 시트가 있다면, 헤더 행에서 `posted` 컬럼 앞에 `image_url` 컬럼을 하나 끼워넣어 헤더 순서를 위와 같이 맞춰주세요. 안 맞추면 새로 추가되는 행에서 이미지 URL 값이 `posted` 칸에 들어가버려 n8n의 미게시 필터(`posted` 빈값 체크)가 깨집니다.

## ⚠️ 먼저 알아야 할 것

- **로그인은 항상 수동**: 브라우저 창이 뜨면 직접 로그인합니다. 로그인 정보는 코드/`.env`/커밋 어디에도 저장되지 않습니다. 로그인 성공 시 세션이 `.storage-state.json`에 저장되어 다음 실행부터는 로그인 단계를 건너뜁니다 (세션 만료 시 다시 로그인 창이 뜸, 최대 5분 대기).
- **구글 서비스계정 키 보안**: `GOOGLE_SERVICE_ACCOUNT_KEY_FILE`이 가리키는 JSON 파일은 절대 커밋/공유하지 마세요.
- **상품 소스**: 검색이 아니라 상품 링크 페이지의 기본 추천상품 목록(약 24개, 골드박스/패션/로켓프레시 등 섹션으로 구성)을 그대로 씁니다.
- **할인율 필터**: 카드 텍스트에서 `NN%` 패턴을 파싱해 `.env`의 `MIN_DISCOUNT_RATE`(기본 90) 이상인 상품만 "링크 생성" 단계로 넘깁니다. 할인율 표시가 없거나 파싱 안 되는 카드는 안전하게 제외됩니다 — 실제 카드에 할인율 배지가 없거나 다른 형식이면 `lib/discount.js`의 `parseDiscountRate` 정규식을 실제 페이지에 맞게 조정해야 합니다.
- **`product_url`/`product_desc` 관련 알려진 한계**: 추천상품 카드에는 상세페이지로 가는 `<a href>`가 없습니다. "상품정보" 버튼으로 URL을 얻을 수는 있지만 WAF(Access Denied) 회피용 별도 처리가 필요하고, 그렇게 얻어도 실제 상세설명은 이미지 배너 위주라 텍스트가 거의 없어(조사 결과 반영) 이 경로는 구현하지 않았습니다. `product_url`은 항상 빈 문자열로 저장되고, `product_desc`는 `product_title`과 동일한 값이 저장됩니다.
- **중복판별(dedup) 기준은 `product_title`**: 원래는 `product_url` 기준을 계획했으나 위 이유로 불가능해 상품명 문자열로 대체했습니다. 동명이인 상품(완전히 같은 이름의 다른 옵션)이 있으면 오탐 가능성이 있는 알려진 한계입니다.
- **간헐적 실패(약 20~30%)**: "링크 생성" 버튼을 못 찾는 실패가 섹션 경계 근처에서 산발적으로 발생합니다(고정 상단 네비게이션과 스크롤 위치가 겹치는 것으로 추정). 스크린샷을 남기고 다음 후보로 넘어가는 정상 동작이며, 크래시하지 않습니다.
- **ToS 리스크**: 쿠팡 파트너스는 자동화를 제한할 수 있습니다. 계정 정지 리스크를 인지하고 진행해주세요.
- **n8n 연동은 별도**: 이 스크립트는 시트에 쓰는 것까지만 합니다. 시트를 읽어 Threads에 자동 게시하는 것은 n8n 워크플로우의 별도 브랜치가 담당합니다.
- **첨부 이미지 합성 (신규)**: 상품 썸네일 사진 아래에 상품명/원가(취소선)/할인가/할인율 배지를 합성한 PNG를 만들어 구글 드라이브에 업로드하고, 공개 링크를 시트의 `image_url` 컬럼에 저장합니다. Threads API는 `image_url`이 공개적으로 접근 가능해야 이미지 첨부 게시가 되므로 드라이브 파일을 "링크가 있는 모든 사용자 - 뷰어"로 자동 공개 처리합니다.
  - 원가(취소선) 표시 위치는 실제 카드 구조를 못 보고 추정한 셀렉터(`lib/generate-coupang-link.js`의 `SELECTORS.originalPriceText`)라 못 찾을 수 있음 — 못 찾아도 치명적 실패는 아니고 합성 이미지에서 원가 줄만 빠짐. 실행하면서 필요하면 셀렉터 조정.
  - 이미지 합성/업로드가 실패해도 (예: 드라이브 API 미활성화, 네트워크 오류) 상품 자체 수집은 계속 진행되고 `image_url`만 빈 값으로 남음.
  - **사전 준비**: 구글 클라우드 콘솔에서 서비스계정과 같은 프로젝트에 "Google Drive API" 사용 설정 필요 (Sheets API 설정한 것과 같은 화면, "라이브러리"에서 검색해서 사용 설정).

## 1. 설치

```bash
cd scripts
npm install
npm run install-browser   # Playwright용 Chromium 다운로드
```

## 2. 구글 서비스계정 준비 (최초 1회)

1. console.cloud.google.com → 프로젝트 생성/선택
2. "API 및 서비스" → "라이브러리" → "Google Sheets API" 사용 설정
3. "사용자 인증 정보" → "사용자 인증 정보 만들기" → "서비스 계정" 생성
4. 서비스계정 → "키" → "키 추가" → JSON 다운로드
5. JSON 안의 `client_email`을 대상 구글시트에 "편집자"로 공유
6. 시트 1행에 헤더 작성: `collected_at | product_title | price | product_desc | product_url | affiliate_link | image_url | posted`

```bash
copy .env.example .env
```

`.env`를 열어 `GOOGLE_SERVICE_ACCOUNT_KEY_FILE`, `GOOGLE_SHEET_ID`, `GOOGLE_SHEET_NAME`을 실제 값으로 채웁니다.

## 4. 단위 테스트 (선택)

```bash
npm test
```

dedup/시트 행 스키마 같은 순수 로직만 검증합니다 (실제 브라우저/구글 API 호출은 포함 안 됨).

## 5. 실행 (`npm run add` — 현재 권장 경로)

### 5.0 (선택, 수기 입력 최소화) 북마클릿으로 상품명/가격/할인율/이미지 자동 인식

`npm run add`는 클립보드 내용을 자동으로 읽어 인식되는 값을 프롬프트 기본값으로 채워줍니다.
아래 북마클릿을 한 번만 등록해두면 상품명/할인가/원가/할인율/이미지 URL 5개를 손으로 안 쳐도 됩니다
("링크 생성" 클릭과 제휴 링크 붙여넣기는 여전히 직접 해야 함 — WAF 때문에 이 부분만은 자동화 불가).

1. 북마크 바에 새 북마크 추가 → 이름 "쿠팡 정보 복사", URL에 아래 한 줄을 그대로 붙여넣기:
   ```
   javascript:(function(){var s=window.getSelection().toString().trim();if(!s){alert('상품 카드 텍스트를 먼저 마우스로 드래그해 선택한 후 다시 클릭하세요.');return;}var n=window.getSelection().anchorNode;var e=n&&n.nodeType===3?n.parentElement:n;var c=e&&e.closest?e.closest('li,div,article'):null;var i=c?c.querySelector('img'):null;var u=i?(i.currentSrc||i.src||''):'';var p=JSON.stringify({raw:s,imageUrl:u});navigator.clipboard.writeText(p).then(function(){alert('복사됨! 터미널로 돌아가 npm run add 를 실행하세요.');},function(){alert('클립보드 복사 실패 - 브라우저 권한을 확인하세요.');});})();
   ```
2. 쿠팡에서 상품 카드를 찾으면 제목/가격/할인율이 보이는 텍스트 전체를 마우스로 드래그해 선택.
3. 북마크 바의 "쿠팡 정보 복사" 클릭 → 클립보드에 복사됨 (자동 클릭/자동 탐색이 아니라 사람이 직접 선택·클릭하는 것이라 WAF와 무관).
4. 이 흐름은 사람이 직접 마우스로 선택한 텍스트를 파싱하는 것이라 카드 레이아웃에 따라 할인가/원가가
   뒤바뀔 수 있음 (첫 "원" 표기=할인가, 마지막 "원" 표기=원가로 추정) — `npm run add` 실행 시 인식된
   값이 표시되니 틀리면 그 줄에서 바로 값을 다시 입력하면 됩니다. 소스: `scripts/bookmarklet.js`.

### 5.1 상품 등록

1. 쿠팡 앱/웹에서 마음에 드는 할인 상품을 직접 찾습니다.
2. (5.0 북마클릿을 등록했다면) 상품 카드 텍스트를 드래그 선택 → 북마클릿 클릭.
3. 그 상품 카드에서 "링크 생성"을 직접 눌러 제휴 링크(`link.coupang.com/...`)를 받습니다.
4. (북마클릿을 안 썼다면) 상품 이미지 우클릭 → "이미지 주소 복사" (선택 — 없으면 이미지 없이 텍스트만 게시됨)
5. 터미널에서:
   ```bash
   npm run add
   ```
6. 클립보드에서 인식된 값이 있으면 먼저 한 줄로 보여줍니다. 프롬프트가 상품명 / 할인가 / 원가 /
   할인율 / 상품 설명 / 상품 URL / 제휴 링크 / 이미지 URL을 순서대로 물어보는데, 인식된 값이 맞으면
   그냥 Enter, 틀리거나 인식이 안 됐으면 직접 입력합니다. 제휴 링크는 항상 직접 붙여넣어야 합니다.
7. 이미지 URL이 있으면 자동으로 할인 배지 합성 → 구글 드라이브 업로드 → 공개 링크 획득까지
   처리한 뒤 시트에 한 줄 추가됩니다.

## 6. (실패, 기록용) 크롬 확장(Claude for Chrome)으로 목록 페이지 자동 수집

2026-08-18에 시도했으나 **`coupang.com` 자체가 navigate 단계에서부터 막힘** (같은 확장에서
`google.com`은 정상 접속, `coupang.com`은 루트 도메인조차 실패 — 캡차/Access Denied 페이지가 뜨는
게 아니라 그 이전에 접근 자체가 차단됨). Playwright(WAF)와는 다른 실행 방식이었지만 결과는 동일 —
자동화 시그널 자체가 도메인 단위로 걸리는 것으로 보임. **이 경로는 재시도하지 않음.**

## 7. 목록 페이지 일괄 수집 (`npm run collect`) — 현실적인 대안

크롬 확장도 막혀서, 사람이 직접(자동화 아님) 쿠팡 목록 페이지에서 여러 상품을 한번에
드래그 선택 + 복사하고, 그 텍스트를 코드가 파싱해서 신규 상품만 시트에 넣는 방식으로 수기 입력을
최소화한다. 쿠팡 접속 자체는 100% 사람이 하는 일반 브라우징이라 WAF와 무관함.

1. `https://www.coupang.com/np/omp#` 접속 → 왼쪽 "할인율" 필터에서 "70% 이상" 클릭.
2. 상품 목록 영역을 마우스로 쭉 드래그해서 여러 카드를 한번에 선택 (몇 개든 상관없음) → `Ctrl+C`.
3. 터미널에서:
   ```bash
   npm run collect
   ```
   먼저 미리보기만 보여줌 (인식된 상품명/판매가/원가/할인율, 신규/중복 개수). 이상 없으면:
   ```bash
   npm run collect -- --commit
   ```
   실제로 신규 상품만 시트에 append됨 (`product_desc`=`product_title`과 동일, `affiliate_link`/
   `image_url`은 빈 값 — 제휴 링크는 여전히 쿠팡 파트너스에서 직접 생성해 시트에 붙여넣어야 함).
4. 이미지(`image_url`)는 이제 필요 없음 — Threads가 댓글의 제휴 링크 자체로 미리보기 썸네일을
   자동 생성해주므로 별도 이미지 합성/업로드 단계를 안 거쳐도 됨.
5. 다음 페이지가 있으면 다시 드래그 선택 + 복사 + `npm run collect -- --commit` 반복.

### 7.0 (선택, 페이지에 따라 안 될 수 있음) 상품 URL도 같이 가져오기

> ⚠️ **2026-08-19 확인**: `/np/omp#` (판매자특가) 페이지는 카드가 `<a href>`가 아니라 `<div>` +
> 배경이미지(CSS `background: url(...)`) + JS 클릭 라우팅으로만 되어있어서 **URL 자체를
> DOM에서 못 가져옴** (실제 카드 HTML로 확인함, 이미지도 `<img>` 태그 아님). 이 페이지에서는
> 아래 북마클릿을 써도 URL은 항상 빈 값 — 그냥 평소처럼 `Ctrl+C`만 써도 결과 동일함.
> 제휴 링크 만들 때는 저장된 상품명으로 쿠팡에서 검색해 들어가면(그때는 주소창에 진짜 URL이
> 뜸) 거기서 "링크 생성" 누르면 됨 — URL 사전수집 없이도 흐름은 그대로 유지됨.
>
> 아래 북마클릿 자체는 삭제하지 않음 — 다른 페이지(진짜 `<a href>`가 있는 목록)에서는 여전히
> 유효할 수 있음.

그냥 드래그+`Ctrl+C`만 하면 화면에 보이는 텍스트만 잡히고 상품 URL(`<a href>` 속성)은 못 잡힘.
제휴 링크를 생성하려면 상품 상세페이지에 들어가야 하므로 URL이 필요함 — 아래 북마클릿을 쓰면
텍스트+URL을 한번에 클립보드로 복사한다(URL이 실제로 있는 페이지에 한해서).

1. 북마크 바에 새 북마크 추가 → 이름 "쿠팡 목록 수집", URL에 아래 한 줄을 그대로 붙여넣기:
   ```
   javascript:(function(){var s=window.getSelection();var t=s.toString().trim();if(!s.rangeCount||!t){alert('먼저 상품 목록을 마우스로 드래그해 선택한 후 다시 클릭하세요.');return;}var f=s.getRangeAt(0).cloneContents();var a=f.querySelectorAll('a[href*="/vp/products/"]');var seen={};var urls=[];for(var i=0;i<a.length;i++){var h=a[i].getAttribute('href')||'';if(h.indexOf('http')!==0)h=location.origin+h;if(h&&!seen[h]){seen[h]=true;urls.push(h);}}var p=JSON.stringify({raw:t,urls:urls});navigator.clipboard.writeText(p).then(function(){alert('복사됨! (상품 URL '+urls.length+'개 포함) collect 페이지로 돌아가 붙여넣으세요.');},function(){alert('클립보드 복사 실패 - 브라우저 권한을 확인하세요.');});})();
   ```
2. 쿠팡 목록 페이지에서 상품 카드 여러 개를 평소처럼 드래그로 선택.
3. `Ctrl+C` 대신 북마크 바의 "쿠팡 목록 수집" 클릭 → 텍스트+URL이 JSON으로 클립보드에 복사됨.
4. `npm run collect` 또는 `쿠팡상품등록.html`에 그대로 붙여넣기 — 자동으로 URL 있는 JSON인지
   인식해서 각 상품에 URL을 순서대로 붙여줌 (웹 화면 미리보기 표의 "URL" 칸에 ✅/❌로 표시됨).
5. 소스: `scripts/bookmarklet-listing.js`. 상품 개수와 인식된 URL 개수가 다르면(선택 범위가
   카드 경계와 안 맞았거나 링크 구조가 바뀐 경우) 뒤쪽 상품부터 URL이 밀릴 수 있음 — 그럴 땐
   드래그 범위를 좁혀서 다시 시도.

### 7.1 터미널 대신 웹 화면으로 (`npm run serve`)

명령어 타이핑 없이 붙여넣기 → 미리보기 → 체크박스 선택 → 버튼 클릭으로 처리하고 싶으면:

```bash
npm run serve
```

브라우저에서 `http://localhost:5175` 접속 → 텍스트 박스에 복사한 내용 붙여넣기(Ctrl+V) →
"미리보기" 클릭 → 표에서 추가할 상품 체크(중복은 자동 회색 처리, 체크 불가) → "체크된 상품 구글
시트에 추가" 클릭. `collect-from-clipboard.js`와 완전히 같은 로직(`lib/parseListingClipboard.js`,
`lib/sheets.js`)을 쓰는 로컬 웹 서버(`collect-server.js`)일 뿐이라 결과는 동일함. 서버는 이 PC
안에서만 열리고(`localhost`), 종료하려면 터미널에서 `Ctrl+C`.

**바탕화면 원클릭 실행**: 바탕화면의 `쿠팡상품등록 실행.bat`을 더블클릭하면 서버가 안 떠있을 때만
자동으로 띄우고(`launch-collect.ps1`, `Get-NetTCPConnection`으로 5175 포트 사용 중인지 확인 —
이미 떠있으면 새로 안 띄움) 바탕화면 `쿠팡상품등록.html`을 자동으로 엶. 서버는 최소화된 cmd 창으로
뜨는데, 계속 켜둬도 되고 다 쓰면 그 창에서 `Ctrl+C`로 끄면 됨. (`쿠팡상품등록.html`을 직접
더블클릭할 수도 있지만, 그 경우 서버는 `npm run serve`로 따로 켜야 함 — CORS 허용은 되어있어서
파일을 직접 열어도 동작은 함.)

**한계**: `lib/parseListingClipboard.js`의 카드 분리 로직은 2026-08-18 스크린샷 기준 레이아웃
("무료배송 · 오늘출발" 뱃지 → 상품명 → "할인율% 원가원" → "판매가원")을 전제로 함. 실제 복사 결과가
다르게 나오면(뱃지 문구가 다르거나 줄바꿈이 다르면) 미리보기 단계에서 이상하게 잘리는 걸로 바로
드러나니, 그 경우 `BADGE_RE`/`extractCardPrice`를 실제 텍스트에 맞게 조정.

## 알려진 한계

- `product_desc`는 실제 상세설명이 아니라 `product_title`과 동일한 값입니다.
- `product_url`은 항상 빈 문자열입니다 (위 "먼저 알아야 할 것" 참고).
- dedup은 `product_title` 문자열 완전 일치 기준이라 동명 상품 오탐 가능성이 있습니다.
- "링크 생성" 클릭 시 약 20~30% 확률로 버튼을 못 찾아 건너뛰는 경우가 있습니다 (섹션 경계 근처, 원인 추정: 고정 헤더와 스크롤 위치 충돌).
- 제외 카테고리(기프트카드, 의료기기 등) 자동 필터링 없음 — 목록에 섞여 있으면 그대로 수집됩니다.
- 합성 이미지는 구글 드라이브 공개 링크(`drive.google.com/uc?export=view&id=...`)로 호스팅됩니다. Threads(Meta) 크롤러가 이 URL을 못 가져오는 경우가 드물게 있을 수 있음 — 실제 게시 테스트에서 이미지가 안 붙으면 다른 호스팅(예: 별도 스토리지 버킷)으로 바꿔야 할 수 있습니다.
